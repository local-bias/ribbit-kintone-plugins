# 🗂️ Googleドライブ連携プラグイン

kintoneのレコードごとにGoogleドライブ上のフォルダを自動作成し、レコード詳細画面・編集画面でフォルダの中身を一覧表示できるプラグインです。ファイルのアップロード(ドラッグ&ドロップ対応)にも対応しています。

[ホームページ](https://ribbit.konomi.app)

## ✨ 特徴

- 指定した親フォルダの直下へ、レコード専用のGoogleドライブフォルダを作成
- フォルダの作成タイミングは3種類から選択可能(下記参照)
- 作成したフォルダのIDは、指定したフィールドに自動保存(編集画面は保存操作時、詳細画面は即時反映)
- レコード詳細画面・編集画面に配置したスペースフィールドへ、フォルダ内のファイル一覧を表示
- ファイルのアップロード — 「Googleドライブ」見出し右端のアイコンからファイルを選択するか、パネル上にファイルをドラッグすると全体がドロップ先としてハイライトされ、そのままドロップしてアップロードできます
- ファイル名をクリックすると、kintoneの画面を離れずにその場でプレビュー表示(PDF・画像・動画・Office文書・Googleドキュメント/スプレッドシート/スライドなど、Googleドライブがプレビュー対応する形式全般に対応)
- ファイル一覧は一定件数を超えると、パネル内でスクロールして確認できます
- Googleアカウントへの接続はブラウザ内のポップアップで完結(バックエンドサーバー不要)
  - ただしGoogleの仕様上、「ウェブアプリケーション」タイプのOAuthクライアントはPKCE使用時もクライアントシークレットを必須とするため、シークレットもプラグイン設定画面に入力する必要があります(下記参照)
  - 初回接続後は`refresh_token`により、タブを閉じたりブラウザを再起動したりしても自動的に再接続されます(明示的にアクセスを取り消さない限り、都度の認証操作は基本的に不要です)。詳細は下記の「トークンの保存について」を参照してください

### フォルダの作成タイミング

条件ごとに、次の3種類から選択できます。

| モード | 動作 |
| --- | --- |
| 自動作成しない | フォルダは自動作成しません。あらかじめ手動でフォルダIDフィールドに値を入力したレコードのみが対象になります。 |
| レコード保存時に作成 | レコードの新規作成・更新の保存直後に自動作成します。この時点でGoogleドライブへの接続(セッション中の認証)が済んでいない場合は作成をスキップします。 |
| 表示スペースでユーザーが操作したときに作成 | レコード詳細/編集画面のパネルに表示される「フォルダを作成」ボタンをユーザーが押したときに作成します。同じパネルから、GoogleドライブのフォルダIDまたはURLを入力して**既存のフォルダを割り当てる**こともできます。 |

### ファイルのプレビューについて

ファイル名をクリックすると、右側にドロワーが開きGoogleドライブ公式のプレビュー機能をその場で表示します。この際、プレビューはこのプラグインのOAuth連携ではなく、**ブラウザに現在ログインしているGoogleアカウント(のCookieセッション)** を使って表示されます。そのため、OAuth連携時に選択したアカウントと、ブラウザに実際にログインしているアカウントが異なる場合、プレビューに「アクセス権がありません」等が表示されることがあります。その場合は「Googleドライブで開く」リンクから直接Driveを開き、アカウントを確認してください。

## ⚠️ 事前準備(Google Cloud Console)

このプラグインはサーバーを介さずブラウザから直接Googleドライブと連携するため、利用開始前に次の準備が必要です。

1. [Google Cloud Console](https://console.cloud.google.com/)でプロジェクトを作成し、**Google Drive API** を有効化する
2. 「APIとサービス」→「認証情報」から **OAuth 2.0 クライアントID**(種類: ウェブアプリケーション)を作成する
3. 作成したクライアントの「承認済みのリダイレクトURI」に、次のURLを登録する

   ```text
   https://kintone-plugin.konomi.app/gdrive-connect/oauth-callback.html
   ```

4. 発行された**クライアントID**と**クライアントシークレット**を、プラグインの設定画面(共通設定タブ)に入力する
5. フォルダの作成先とする、Googleドライブ上の親フォルダを用意し、**接続に使用するGoogleアカウントに「編集者」権限で共有しておく**
   - ブラウザに複数のGoogleアカウントでログインしている場合、「Google Driveに接続」をクリックするたびにアカウント選択画面が表示されます。フォルダを共有した**正しいアカウント**を選択してください
   - 「フォルダが見つかりません(File not found)」エラーが出る場合、多くは接続したアカウントと共有先アカウントの不一致が原因です
6. 対象のkintoneアプリに、生成したフォルダIDを保存するための**単一行テキストフィールド**を1つ用意する

設定画面では、上記フィールドの選択に加えて、表示先のスペースフィールド・親フォルダID・フォルダ名に使用するフィールドを指定します。

> ⚠️ **クライアントシークレットの取り扱いについて**
> Googleの現行仕様では、「ウェブアプリケーション」タイプのOAuthクライアントはPKCE(Authorization Code + PKCE)を使用していてもトークン交換時にクライアントシークレットを必須とします。本プラグインはバックエンドサーバーを持たないため、クライアントシークレットもプラグイン設定として保存せざるを得ません。この値は該当kintone環境の管理者であれば(プラグイン設定のエクスポートやブラウザの開発者ツール経由で)参照可能であり、完全な機密情報としては扱われない点にご注意ください。より厳密にシークレットを秘匿したい場合は、コード交換のみを代行する簡易なバックエンド(Cloudflare Workersなど)を別途用意する構成に変更することを検討してください。

### 🔐 トークンの保存について

利便性のため、初回接続時に取得した`refresh_token`をブラウザの`localStorage`に保存し、以降はポップアップなしでアクセストークンを自動更新します。これにより、タブを閉じたりブラウザを再起動したりしても、明示的にアクセスを取り消すまで再接続は基本的に不要になります。

- `refresh_token`はアクセストークンより長期間有効な認証情報であり、`localStorage`への保存は`client_secret`と同様、この構成(バックエンドなし)における既知のトレードオフです。kintone環境がXSS等で侵害された場合の影響範囲は、都度再接続が必要な方式より広くなります
- Google Cloud ConsoleのOAuth同意画面が「テスト」ステータス(未検証の外部アプリ)の場合、`refresh_token`は**発行から7日で失効**します。「内部」(Google Workspace組織限定)または「本番環境」(検証済み)ステータスであれば、取り消されるまで有効です
- 接続を明示的に取り消したい場合は、[Googleアカウントの「サードパーティ製アプリとサービスへのアクセス権」](https://myaccount.google.com/connections)から本アプリのアクセスを削除してください

## 🔧 使い方

### パッケージのインストール

```
pnpm install
```

### プラグインの秘密キーと SSL 証明書の作成

```
pnpm run init
```

### ご利用の kintone へアップロード + ファイルの変更を監視

```
pnpm run dev
```

### リリース用 zip ファイルの生成

```
pnpm run build
```
