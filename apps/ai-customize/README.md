# 🐸 kintone AIカスタマイズプラグイン(開発中)

kintoneアプリで管理するJavaScript・CSSのカスタマイズを、**カスタマイズごとの権限つき**で対象アプリに適用するプラグインです。
AIとの対話でカスタマイズを作る機能は、この実行基盤の上に今後追加します。設計は [docs/](./docs/README.md) を参照してください。

## 現在の実装範囲(MVP)

| 機能 | 状態 |
| --- | --- |
| 設定画面: アセット管理アプリ・フィールド・選択肢の値の対応付け | ✅ |
| 起動ゲート: 初回表示から通常のJSカスタマイズと同じタイミングで適用(キャッシュなし) | ✅ |
| 標準の `kintone.events.on` で書けるイベント購読(アセットごとの持ち主つき) | ✅ |
| カスタマイズ単位の権限: GETは常時、追加・更新・削除・外部通信(指定先のみ / すべて)・制限なし | ✅ |
| 迂回できる書き方の静的検出(「制限なし」が無いと実行しない) | ✅ |
| 影響範囲(自分だけ / 全員)、適用画面、実行順 | ✅ |
| セーフモード(`?ai-customize=off`)、エラー隔離、サーキットブレーカー | ✅ |
| 画面右下の最小限の通知(読み込み失敗・権限による停止など) | ✅ |
| ランチャー・一覧・有効スイッチ・権限スイッチ(docs/06) | 未実装(P2) |
| AIチャット(docs/07) | 未実装(P3・P4) |

## 使い方

1. kintoneで**アセット管理アプリ**を作り、[docs/04-asset-app.md](./docs/04-asset-app.md) の表のとおりにフィールドを置きます。
   - 「権限」チェックボックスの**初期値は全て未選択**にしてください(未選択 = 読み取りのみ)。
   - アクセス権は [docs/08-security.md](./docs/08-security.md) 2章の推奨設定にしてください。
2. カスタマイズを適用したいアプリにこのプラグインを追加し、設定画面で管理アプリとフィールドを対応付けます。
3. 管理アプリにレコードを追加します。対象アプリID・種別・コード・影響範囲・状態を入れると、次に対象アプリを開いたときから適用されます。

```js
// アセットのコード例(通常のJSカスタマイズと同じ書き方)
kintone.events.on('app.record.create.show', (event) => {
  event.record.Status.value = '未着手';
  event.record.Status.disabled = true;
  return event;
});
```

レコードの追加・更新・削除を行うカスタマイズは、「権限」で該当する操作を選んでください。選んでいない操作は実行時に止まり、画面右下に通知が出ます。

### 困ったとき

- 画面が操作できなくなったら、URLに `?ai-customize=off` を付けて開き直してください(セーフモード)。全てのカスタマイズを止めて開けます。
- 詳細なエラーは、ブラウザの開発者ツールのコンソールに `[ai-customize]` の接頭辞で出ます。

## 開発

```sh
pnpm test          # 単体テスト + 起動処理の結合テスト
pnpm check-types   # 型チェック
pnpm build:js      # desktop.js / config.js のビルド
pnpm run init      # 初回のみ: 署名鍵(.plugin/private.ppk)の生成。プラグインIDが決まるため、リリース担当者が行う
```
